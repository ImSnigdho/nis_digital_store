# UI/UX Requirements

**Design Direction:**

Our app and website follow the Glassmorphism design style.

**Brand Color Palette & Styling Tokens:**

| Styling Tokens | Hex Codes   |
| --- | --- |
| Primary   | #3B82F6   |
| Secondary   | #64748B   |
| Accent   | #06B6D4   |
| Background   | #0F172A   |
| Surface   | #1E293B   |
| Text   | #F8FAFC   |
| Gradient   | N/A (not applicable for mobile app) |

**Core Screens:**

1. **Homepage:** Product grid or list layout with search functionality.
2. **Product Detail:** Detailed view of a single product with options to add to cart or wishlist.
3. **Cart:** View cart, checkout, and order history.
4. **Wishlist:** View wishlist, search, and checkout.
5. **Profile:** User profile with options to update information, edit orders, and manage account settings.

**Responsive Breakpoints:**

- Mobile: 320px wide
- Tablet: 768px wide
- Desktop: 1280px wide

**Accessibility expectations:**

- Keyboard navigation
- Screen reader compatibility
- High contrast mode
