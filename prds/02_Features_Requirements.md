# Features & Requirements

**Authentication:**

1. Supabase Authentication for user registration and login.
2. Supabase Authentication for admin panel access with required permissions.

**Core feature set:**

1. **Product Browse:** Users can browse and view products through a list or grid layout.
2. **Search Feature:** Advanced search functionality to filter products by brand, category, and price range.
3. **Filters:** Customizable filters to narrow down product options.
4. **Cart and Wishlist:** Functionality to add and remove products, view cart and wishlist.
5. **Secure Checkout:** Secure payment gateway (manual verification) with a built-in process for users to provide payment information.

**Data the app needs to store:**

1. **Products:** Product details, images, and categories.
2. **Users:** User registration information, profile, and order history.

**Backend/Database:** Supabase
